quit {Rsession} R Documentation

Terminate an R Session

Description


The function quit or its alias q terminate the current R session.

Usage

quit(
    save = "no",
    status = 0,
    runLast = TRUE);

Arguments

save

a character string indicating whether the environment (workspace) should be saved, one of "no", "yes", "ask" or "default". [as string]

status

the (numerical) error status to be returned to the operating system, where relevant. Conventionally 0 indicates successful completion. [as integer]

runLast

should .Last() be executed?. [as boolean]

Details

Authors

R# language

Value

This function has no value returns.
